# This Is a Fork of [Immersive Armors](https://github.com/Luke100000/ImmersiveArmors)
Immersive armors only supports 'Major' minecraft versions (1.21 1.21.11 26.1.2 26.2) this simple fork intends to extend support to (future) minor versions, such as 26.3 and when it releases 26.4 as well as possibly eventually past unsupported versions such as 1.12 1.9 1.8.9 and so on

This port was created mainly for [LiteHearted](https://modrinth.com/modpack/litehearted) so that the mod could be maintained, seeing as immersive armors is a simple enough mod for me to easily port myself, that way players dont loose their hard-earned items (:

Additionally, items you may have obtained in the original Immersive armors mod will still exist, as the internal IDs of all the items are identical... all this project does is update it to modern versions it does not add nor change anything the mod has normally

Please note, the actual amount of difference in code within this mod and the original mod is incredibly minute... nearly nothing in fact as it simply replaces any deprecated functions that it used in the past version with correct 'maintained' ways of doing things, the version with the largest amount of code changes is guaranteed to be 26.3, because I will undoubtedly have to replace hundreds if not thousands of deprecated functions with actually maintained ones as the immersive armors mod only supports major versions and thus does not have to care about swapping over from deprecated functions before they die and no longer work

Do note, this treatment will not be extended to every mod in the pack that becomes 'Abandoned' or supports only 'major' (Whatever thats supposed to mean... all versions of the game took the developers actual effort to create, so its quite rude to discount any version by calling it a 'minor' version but thats just my personal opinion, its not a popular one) versions, but rather only mods that are essential to it working
